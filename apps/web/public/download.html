macOS 首次安装与打开

打开 DMG，将 Opentu 拖到“应用程序”后启动。预览版尚未完成 Apple 公证；如提示“已损坏”或“无法验证开发者”，核对下载来源与 SHA-256 后，在终端执行：

xattr -dr com.apple.quarantine "/Applications/Opentu.app"
open "/Applications/Opentu.app"

安装路径不同时，请替换实际路径。这仅手动放行此应用，不代表已通过 Apple 公证。

如何确认安装包完整？

下载卡片中的 SHA-256 链接提供对应安装包的校验值，可与本地下载文件的 SHA-256 比对。没有校验文件的安装包会明确标注。

所有下载入口均指向项目的 GitHub Release。

已安装旧版本，如何更新？

应用会检查更高版本。已安装 1.2.16 的用户升级本次预览修复包时，请手动下载并安装；相同版本号不会触发自动升级提醒。

源代码、更新日志和历史安装包可在 GitHub Release 查看。
